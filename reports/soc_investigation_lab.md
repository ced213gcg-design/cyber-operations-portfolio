# SOC Investigation Lab

## Scenario
Suspicious login detected on monitored host.

## Investigation Steps
1. Review authentication logs
2. Identify source IP address
3. Determine login method
4. Check for repeated login attempts
5. Identify unusual geolocation

## Findings
Example indicators:
- Multiple failed login attempts
- Login from unknown IP
- Access outside normal hours

## Analyst Actions
- Flag suspicious IP
- Recommend account password reset
- Recommend MFA enforcement

## Conclusion
The investigation identified suspicious login activity that warrants monitoring and possible credential reset.
